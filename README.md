# Kivora

Kivora is an original fintech dashboard concept inspired by the supplied reference site’s dark payment-product direction. It is a standalone build with a new name, logo, layout, and interaction system.

## Preview

Open `dist/index.html` in a browser. The build is dependency-free and uses inline SVG for the brand mark and chart visuals.

## Included

- Responsive glassmorphism dashboard
- Original Kivora mark and wordmark
- Revenue chart and payment-method visualization
- Responsive navigation with mobile drawer
- Payment creation modal
- Toast feedback, filters, exports, chart periods, and hover states
- Reduced-motion support
